## Setup on Ubuntu

Your `~/Documents/codeverse` directory currently contains `CODEVERSE_MASTER_PLAN.md`. Extract the source archive into this same directory, keeping the master plan:

```bash
cd ~/Documents/codeverse
unzip -o ~/Downloads/CODEVERSE_Phases_0_to_8_Source.zip
bash scripts/bootstrap-ubuntu.sh
npm run dev
```

Open the local URL printed by Vite (normally `http://127.0.0.1:5173`). No public exposure is needed.

If `unzip` isn't installed, run `sudo apt install unzip` first. If npm fails, paste the **actual error**; do not reinstall Node on speculation.

## Repository setup and GitHub push

`bootstrap-ubuntu.sh` initializes **a local Git repository** if one does not already exist. When dependencies, TypeScript, tests, and build succeed:

```bash
cd ~/Documents/codeverse
git status
git add .
git commit -m "feat: build CODEVERSE Python City alpha"
```

To publish on GitHub, **first create a new empty repository named `codeverse`** under your own GitHub account. Do not create it with an autogenerated README, license or .gitignore because the local project already supplies these. Then:

```bash
git remote add origin https://github.com/derrenderrick00-ux/codeverse.git
git push -u origin main
```

The URL is the planned remote destination, **not an assertion that the GitHub repository already exists**. If an `origin` remote is already configured, inspect it using `git remote -v` instead of adding a duplicate. Do not upload personal progress backups, credentials or `.env` files.

## What really runs?

The **restricted deterministic Python teaching tracer** runs only top-level assignments, numbers, strings, Booleans, `None`, lists, indexing, simple arithmetic, `len(...)`, `append(...)` and `print(...)`. It is **not** a Python interpreter and does not execute loops, functions, classes, files, imports, set/dict literals, lambdas or arbitrary Python. For those 18 advanced topics, step-by-step illustrations are **explicitly labeled guided**, the full code sample is read-only, and CODEVERSE recommends running examples locally in Python 3.

No `eval`, dynamic `Function`, or backend process executes arbitrary user code. Future supported interpreters will be independent modules with strict resource and isolation controls.

## Progress and mastery

Local IndexedDB saves lesson views, scores, attempts, hints and example source. JSON imports are checked fully **before** overwriting local records. Backups never leave your browser unless you download them yourself. A damaged record triggers an error instead of an automatic reset. Real topic mastery requires nine steps, three checks, mini-project and integrated main-project evidence. Not all advanced lessons can yet satisfy these gates: this alpha deliberately does not award unsupported mastery.

## Hardware & accessibility

The 2D atlas is the default to conserve RAM. Enable 3D from the top bar. 3D assets are lazy loaded and reduced motion is honored. All five worlds have accessible 2D cards. World content beyond Python is a labeled preview, not a fabricated implementation.
